# NEYTHAL: saree house storefront (front-end demo)

Vite + React 19 + TypeScript + Tailwind CSS 4 + Motion + React Router. No backend: checkout and accounts are demos.

    npm install
    npm run dev        # http://localhost:5173
    npm run lint && npm run build

Customise: `src/config/brand.ts` (name, promo codes/date, thresholds, contact, social), `src/data/products.ts`,
`src/data/content.ts` (categories, FAQ, sample reviews), `src/data/images.ts` + `public/img` (photography; credits in `public/img/CREDITS.txt`).
